ESP32 Web Flasher

Flash ESP32 / Espressif firmware straight from the browser (Web Serial + esptool-js).

Requires Chrome/Edge 89+ (Web Serial), over HTTPS or localhost.

1. Firmware version

Upload binaries first, e.g. curl -F version=v1.0.0 -F files=@bootloader-esp32.bin -F files=@partition-table-esp32.bin -F files=@firmware-esp32.bin http://localhost:5060/api/upload
